# Screenshots

These PNGs are auto-generated by `scripts/take_screenshots.py` against a clean
bt-spy instance seeded with synthetic demo data (`scripts/seed_demo_data.py`) —
no real BD_ADDRs or device names. To regenerate:

```bash
# Wipe + reseed demo DB
BTSPY_DATA_DIR=/tmp/bt-spy-screenshots .venv/bin/python scripts/seed_demo_data.py

# Start a clean bt-spy serve against that DB (in another terminal):
BTSPY_DATA_DIR=/tmp/bt-spy-screenshots .venv/bin/bt-spy serve

# In the original terminal:
.venv/bin/python scripts/take_screenshots.py
```

Playwright + chromium need to be installed: `.venv/bin/pip install playwright &&
.venv/bin/playwright install chromium`.
